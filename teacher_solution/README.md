# Teacher Solution: интерактивный детектив

Эта папка содержит полное решение проекта для преподавателя.

Структура совпадает с проектом, который получают ученики: все файлы лежат прямо в папке проекта.

Главное отличие:

- в ученическом `data.py` пустые переменные и инструкции;
- в `teacher_solution/data.py` данные полностью заполнены;
- в ученических файлах функций стоят заглушки;
- в `teacher_solution/` эти же функции полностью реализованы.

## Файлы команды 1

- `main_menu.py`;
- `difficulty.py`;
- `game_state.py`;
- `final.py`.

## Файлы команды 2

- `case_view.py`;
- `suspects_view.py`;
- `clues_view.py`;
- `interview.py`;
- `hints.py`.

## Проверка

Из папки `teacher_solution/` можно запустить:

```bash
python main.py
```

Проект должен проходиться от начала до конца.
