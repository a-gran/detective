# План работы с teacher_solution

`teacher_solution/` нужен преподавателю как эталон.

## Как устроена пара файлов

Ученический файл:

```text
interview.py
```

Файл решения:

```text
teacher_solution/interview.py
```

Оба файла содержат одинаковые функции.

В ученическом файле функции являются заданиями.

В решении функции полностью написаны.

## Как использовать

1. Дать ученикам проект без папки `teacher_solution/`.
2. Оставить `teacher_solution/` у преподавателя.
3. После занятия сравнить решения учеников с эталоном.
4. Если ученики застряли, показывать не весь файл, а маленький фрагмент нужной функции.
5. Для проверки отдельной функции запускать соответствующий файл напрямую.
