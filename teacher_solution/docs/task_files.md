# Файлы решения для преподавателя

Эта папка повторяет структуру ученического проекта.

## data.py

В ученическом проекте `data.py` содержит инструкции и пустые переменные.

В `teacher_solution/data.py` эти переменные заполнены готовым примером расследования.

## Команда 1

В ученическом проекте команда 1 получает четыре файла-задания:

- `main_menu.py`;
- `difficulty.py`;
- `game_state.py`;
- `final.py`.

В `teacher_solution/` лежат файлы с такими же именами, но функции уже реализованы.

## Команда 2

В ученическом проекте команда 2 получает пять файлов-заданий:

- `case_view.py`;
- `suspects_view.py`;
- `clues_view.py`;
- `interview.py`;
- `hints.py`.

В `teacher_solution/` лежат файлы с такими же именами, но функции уже реализованы.

## main.py

`main.py` в решении подключает те же функции, что и ученический `main.py`.

Это нужно, чтобы преподаватель мог сравнивать заглушку и готовую реализацию по одному и тому же имени функции.

## Проверка отдельных файлов

В `teacher_solution/` каждый файл тоже можно запускать отдельно.

Например:

```bash
python difficulty.py
python interview.py
```

Так преподаватель может показать ученику маленькую проверку конкретной функции.
