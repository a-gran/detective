# Части проекта и готовое решение

Ученики получают проект с заглушками.

Преподаватель хранит готовую версию в `teacher_solution/`.

## Как сравнивать

Файл ученика:

```text
main_menu.py
```

Файл решения:

```text
teacher_solution/main_menu.py
```

Имена функций совпадают.

Разница только в том, что у ученика внутри функции стоит инструкция и `NotImplementedError`, а у преподавателя внутри функции готовый код.

## Что проверять

Преподаватель может смотреть:

- заполнены ли данные в `data.py`;
- реализованы ли функции команды 1;
- реализованы ли функции команды 2;
- запускается ли `python main.py`;
- проходит ли игра от начала до конца.

Каждый файл решения можно запускать отдельно, чтобы показать ученику локальную проверку без всей игры.
