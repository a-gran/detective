# Интерактивный детектив

Учебный проект на Python: консольная игра-детектив.
Игрок читает описание дела, изучает подозреваемых и улики, задает вопросы, берет подсказки и в конце выбирает преступника.

## Структура проекта

```text
main.py
data.py
deepseek_client.py

menu.py
difficulty.py
game_state.py
final.py

case.py
suspects.py
clues.py
interview.py
hints.py

docs/
```

## Что делают ученики

Ученики должны:

1. заполнить данные в `data.py`;
2. реализовать функции в файлах-заданиях;
3. проверять отдельные файлы;
4. запускать `main.py`, когда несколько частей уже готовы.

## Готовые файлы

`main.py` - готовый файл запуска. Ученики его не пишут. Он соединяет все функции проекта и запускает игру.
`deepseek_client.py` - готовая учебная заглушка для будущего подключения DeepSeek. Сейчас файл не отправляет запросы в интернет.

## Файл данных

`data.py` - файл-задание.
В нем нет готового дела. Ученики сами заполняют переменные:

- `GAME_TITLE`;
- `MAIN_MENU_ITEMS`;
- `RULES_TEXT`;
- `DIFFICULTY_SETTINGS`;
- `GAME_ACTIONS`;
- `RESULT_TEXTS`;
- `CASE_DATA`;
- `INTERVIEW_QUESTIONS`;
- `SUSPECTS`;
- `CLUES`;
- `HINTS`.

Внутри `data.py` есть комментарии: какой тип данных нужен, какие ключи должны быть в словаре и какие данные должны совпадать между собой.
Проверка файла данных:

```bash
python data.py
```

## Команда 1

Команда 1 отвечает за игровой процесс.
Файлы команды 1:

- `menu.py` - главное меню, правила, разделитель, ожидание Enter;
- `difficulty.py` - выбор сложности;
- `game_state.py` - состояние игры, меню расследования, история допросов;
- `final.py` - финальное обвинение и проверка ответа.

Проверка файлов команды 1:

```bash
python menu.py
python difficulty.py
python game_state.py
python final.py
```

## Команда 2

Команда 2 отвечает за расследование.
Файлы команды 2:

- `case.py` - показ описания дела;
- `suspects.py` - показ и выбор подозреваемых;
- `clues.py` - показ улик;
- `interview.py` - вопросы и допрос;
- `hints.py` - подсказки.

Проверка файлов команды 2:

```bash
python case.py
python suspects.py
python clues.py
python interview.py
python hints.py
```

## Как проверять работу

Сначала ученик проверяет свой файл отдельно.
Например:

```bash
python difficulty.py
```

Если файл пишет:

```text
Нужно доделать задание
```

значит нужно открыть указанный файл и реализовать указанную функцию.
Когда несколько файлов уже готовы, можно запускать всю игру:

```bash
python main.py
```

## Что считается готовым проектом

Проект готов, если игрок может:

1. запустить игру;
2. выбрать сложность;
3. прочитать описание дела;
4. посмотреть подозреваемых;
5. изучить улики;
6. провести допрос;
7. получить подсказку;
8. назвать преступника;
9. увидеть результат расследования.
