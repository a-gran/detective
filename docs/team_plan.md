# План разделения задач между командами

Проект делится на данные и функциональность.

Все файлы-задания лежат в корне проекта.

## Главная идея

Ученики получают проект без готового решения.

Они должны:

- заполнить `data.py`;
- реализовать 4 файла команды 1;
- реализовать 5 файлов команды 2;
- запускать `main.py` для проверки.

## data.py

`data.py` можно дать всем ученикам как общее задание.

В нем нужно заполнить:

- название игры;
- правила;
- сложности;
- действия;
- дело;
- вопросы;
- подозреваемых;
- улики;
- подсказки;
- финальные тексты.

## Команда 1

Команда 1 состоит из 4 человек.

Файлы команды:

1. `main_menu.py` - главное меню и правила.
2. `difficulty.py` - выбор сложности.
3. `game_state.py` - состояние игры, меню расследования и история.
4. `final.py` - финальное обвинение.

Каждый файл содержит заглушки функций и комментарии с инструкциями.

## Команда 2

Команда 2 состоит из 5 человек.

Файлы команды:

1. `case_view.py` - показ дела.
2. `suspects_view.py` - показ и выбор подозреваемых.
3. `clues_view.py` - показ улик.
4. `interview.py` - допрос.
5. `hints.py` - подсказки.

Каждый файл содержит заглушки функций и комментарии с инструкциями.

## Порядок работы

1. Сначала ученики заполняют минимальные данные в `data.py`.
2. Потом команда 1 реализует меню, сложность и состояние.
3. Потом команда 2 реализует показ дела, улик и допрос.
4. После каждой функции ученик запускает свой файл отдельно.
5. После сборки нескольких частей команда запускает `python main.py`.
6. Если программа показывает `Нужно доделать задание`, ученики находят указанный файл и функцию.

## Как проверять отдельно

Команда 1:

```bash
python main_menu.py
python difficulty.py
python game_state.py
python final.py
```

Команда 2:

```bash
python case_view.py
python suspects_view.py
python clues_view.py
python interview.py
python hints.py
```

## Минимальная проверка готового проекта

Когда все функции сделаны, нужно проверить:

1. игра запускается;
2. меню работает;
3. можно выбрать сложность;
4. можно посмотреть дело;
5. можно посмотреть подозреваемых;
6. можно посмотреть улики;
7. можно допросить персонажа;
8. можно получить подсказку;
9. можно назвать преступника;
10. игра показывает результат.
