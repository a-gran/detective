# План разделения задач между командами

Этот документ описывает первый вариант разделения проекта на готовую часть и задачи для двух команд.

План можно изменить после обсуждения с преподавателем и студентами.

## Главная идея разделения

Проект уже имеет рабочую основу.

Лучше разделить его так:

- преподаватель дает готовое ядро;
- студенты меняют и улучшают контент;
- команды пробуют разные реализации;
- в конце выбираются лучшие варианты.

## Что дать готовым

Эти части лучше дать студентам уже готовыми:

- `main.py`;
- запуск игры;
- главное меню;
- выбор сложности;
- игровой цикл;
- допросы;
- подсказки;
- финальное обвинение;
- проверка правильного ответа;
- базовая документация.

Причина: эти части являются ядром игры. Если они сломаются, проект перестанет работать.

## Что можно дать студентам

Главный файл для студентов:

```text
data.py
```

В нем можно менять:

- название дела;
- описание преступления;
- правильного преступника;
- правильное объяснение;
- подозреваемых;
- алиби;
- секреты персонажей;
- ответы на вопросы;
- улики;
- подсказки.

## Правило работы команд

Задачи не закрепляются жестко за конкретными детьми.

У каждой команды есть общий пул задач. Несколько участников могут сделать разные варианты одной задачи. Потом команда выбирает лучший вариант.

Такой подход помогает, если кто-то не успел, не понял или сделал нерабочий вариант.

## Команда 1: игровой процесс

Команда 1 состоит из 4 человек.

Пул задач команды:

1. Улучшить главное меню.
2. Улучшить меню расследования.
3. Улучшить уровни сложности.
4. Улучшить историю допросов.

## Возможные задания для команды 1

### Улучшить главное меню

Можно добавить:

- более красивый заголовок;
- пункт "Об авторах";
- пункт "Краткое описание игры";
- понятные сообщения при неправильном вводе.

### Улучшить меню расследования

Можно добавить:

- пункт "Краткая сводка";
- пункт "Что я уже знаю";
- показ изученных улик;
- предупреждение перед финальным обвинением.

### Улучшить уровни сложности

Можно изменить:

- количество вопросов;
- количество подсказок;
- названия сложностей;
- описание сложностей.

### Улучшить историю допросов

Можно сделать так, чтобы история показывала:

- имя подозреваемого;
- номер вопроса;
- текст ответа;
- сколько вопросов осталось после допроса.

## Команда 2: контент и история

Команда 2 состоит из 5 человек.

Пул задач команды:

1. Придумать новое дело.
2. Улучшить подозреваемых.
3. Улучшить улики.
4. Улучшить допросы.
5. Улучшить подсказки.

## Возможные задания для команды 2

### Придумать новое дело

Нужно подготовить:

- название дела;
- место преступления;
- что пропало или случилось;
- почему это важно;
- что игрок знает в начале.

### Улучшить подозреваемых

Для каждого подозреваемого нужно придумать:

- имя;
- роль;
- характер;
- алиби;
- секрет;
- отношение к другим персонажам.

### Улучшить улики

Для каждой улики нужно придумать:

- название;
- описание;
- где нашли улику;
- почему она важна;
- настоящая это улика или ложный след.

### Улучшить допросы

Можно улучшить:

- вопросы игрока;
- ответы подозреваемых;
- стиль речи персонажей;
- намеки в ответах;
- ложные версии.

### Улучшить подсказки

Подсказки должны:

- помогать думать;
- не раскрывать ответ сразу;
- указывать на важные детали;
- быть короткими и понятными.

## Как выбирать лучшие реализации

Команда выбирает вариант, который:

- запускается без ошибок;
- легко понять;
- интересно читать;
- не ломает сюжет;
- не раскрывает преступника слишком рано;
- легко вставить в общий проект.

Самый сложный вариант не всегда лучший. Для учебного проекта важнее, чтобы решение было понятным и рабочим.

## Какие файлы можно менять

На первом этапе студентам можно менять:

```text
data.py
README.md
docs/student_parts.md
docs/team_plan.md
```

Файл `main.py` лучше менять только вместе с преподавателем.

## План работы по занятиям

### Занятие 1

- запустить готовую игру;
- пройти игру как игроки;
- посмотреть структуру проекта;
- понять разницу между `main.py` и `data.py`.

### Занятие 2

- команда 1 предлагает улучшения меню;
- команда 2 предлагает новое описание дела;
- выбираются лучшие варианты.

### Занятие 3

- команда 1 улучшает уровни сложности;
- команда 2 улучшает подозреваемых;
- проверяется запуск игры.

### Занятие 4

- команда 1 улучшает историю допросов;
- команда 2 улучшает улики;
- проверяется логика расследования.

### Занятие 5

- команда 1 улучшает меню расследования;
- команда 2 улучшает ответы подозреваемых;
- проводится тестовое прохождение.

### Занятие 6

- команда 1 помогает собрать лучшие изменения;
- команда 2 улучшает подсказки и финальное объяснение;
- проводится первое полное тестирование.

### Занятие 7

- обсуждается подключение DeepSeek;
- включается учебная заглушка или настоящий API;
- проверяется, что модель не меняет факты дела.

### Занятие 8

- проводится финальное тестирование;
- исправляются последние ошибки;
- готовится презентация;
- проект показывается эксперту.

## Минимальная проверка после изменений

После каждого изменения нужно запустить:

```bash
python main.py
```

И проверить:

1. игра запускается;
2. меню работает;
3. можно выбрать сложность;
4. можно посмотреть дело;
5. можно посмотреть подозреваемых;
6. можно посмотреть улики;
7. можно допросить персонажа;
8. можно получить подсказку;
9. можно назвать преступника;
10. игра показывает результат.
