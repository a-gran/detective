# Две версии проекта

В проекте используются две версии:

- публичная ученическая версия;
- скрытая преподавательская версия.

## Публичная ученическая версия

Эта версия лежит в корне проекта.

Основные файлы:

```text
main.py
data.py
deepseek_client.py
README.md
docs/
```

Именно эти файлы можно отправлять на GitHub.

Ученики будут видеть:

- готовое ядро игры;
- данные, которые можно менять;
- документацию;
- учебную заглушку DeepSeek.

## Скрытая преподавательская версия

Эталонная версия лежит в папке:

```text
teacher_solution/
```

Эта папка добавлена в `.gitignore`, поэтому она не должна отправляться на GitHub.

В ней можно хранить:

- полностью готовый вариант проекта;
- правильные реализации;
- проверочные материалы;
- варианты решений после каждого занятия.

## Зачем нужна teacher_solution

Папка `teacher_solution/` нужна преподавателю как ответник.

С ее помощью можно:

- сравнивать решения студентов с готовым вариантом;
- быстро восстановить рабочую версию;
- проверять, что студенты не сломали ядро;
- заранее подготовить финальную реализацию.

## Важное правило

Если папка `teacher_solution/` уже была добавлена в git, `.gitignore` не удалит ее из истории автоматически.

Тогда нужно выполнить:

```bash
git rm -r --cached teacher_solution
```

После этого сделать commit.

Если папка никогда не добавлялась в git, ничего дополнительно делать не нужно.

## Как проверить, что папка скрыта

Можно выполнить:

```bash
git status --ignored
```

В обычном списке изменений `teacher_solution/` быть не должно.

Она может появиться только в разделе ignored.
