# Файлы заданий для учеников

Проект выдается ученикам без готового решения.

Все файлы-задания лежат прямо в корне проекта.

Ученики запускают `main.py`, но реализуют задания в отдельных файлах.

## Готовые файлы

- `main.py` - запускает игру и соединяет части проекта;
- `deepseek_client.py` - учебная заглушка для будущего DeepSeek.

Эти файлы ученики обычно не меняют.

## data.py

`data.py` - файл-задание для данных.

В нем ученики должны заполнить переменные:

- `GAME_TITLE` - строка с названием игры;
- `MAIN_MENU_ITEMS` - словарь пунктов главного меню;
- `RULES_TEXT` - список строк с правилами;
- `DIFFICULTY_SETTINGS` - словарь уровней сложности;
- `GAME_ACTIONS` - словарь действий расследования;
- `RESULT_TEXTS` - словарь финальных текстов;
- `CASE_DATA` - словарь с описанием дела;
- `INTERVIEW_QUESTIONS` - словарь вопросов;
- `SUSPECTS` - список словарей с подозреваемыми;
- `CLUES` - список словарей с уликами;
- `HINTS` - список строк с подсказками.

В `data.py` есть комментарии с типами данных и примерами.

## Команда 1

Команда 1 реализует игровой процесс.

Файлы команды:

- `menu.py` - главное меню, правила, разделитель и ожидание Enter;
- `difficulty.py` - выбор уровня сложности;
- `game_state.py` - состояние игрока, меню расследования и история допросов;
- `final.py` - финальное обвинение и проверка ответа.

В каждом файле есть функции-заглушки и инструкции, что нужно написать.

## Команда 2

Команда 2 реализует действия расследования.

Файлы команды:

- `case.py` - показ описания дела;
- `suspects.py` - показ и выбор подозреваемых;
- `clues.py` - показ улик;
- `interview.py` - вопросы и допрос;
- `hints.py` - подсказки.

В каждом файле есть функции-заглушки и инструкции, что нужно написать.

## Проверка

После реализации части задания нужно запускать:

```bash
python main.py
```

Если какая-то функция еще не сделана, программа покажет сообщение `Нужно доделать задание`.

## Проверка отдельного файла

Каждый файл можно проверять отдельно, даже если другие ученики еще не закончили свои функции.

Для проверки данных:

```bash
python data.py
```

Для проверки файлов команды 1:

```bash
python menu.py
python difficulty.py
python game_state.py
python final.py
```

Для проверки файлов команды 2:

```bash
python case.py
python suspects.py
python clues.py
python interview.py
python hints.py
```

Если отдельный файл пишет `Нужно доделать задание`, значит нужно открыть указанный файл и реализовать указанную функцию.

Полную игру нужно проверять после того, как основные функции уже сделаны:

```bash
python main.py
```
