# Архитектура проекта

Этот документ объясняет, как устроен проект "Интерактивный детектив" и какие части в нем есть.

## Общая идея

Проект сделан как консольная игра на Python.

Игрок проходит расследование:

1. выбирает сложность;
2. читает описание дела;
3. изучает подозреваемых;
4. изучает улики;
5. задает вопросы;
6. использует подсказки;
7. выбирает преступника;
8. получает результат.

## Текущая структура проекта

```text
intensive_detective/
├── main.py
├── data.py
├── deepseek_client.py
├── README.md
└── docs/
    ├── architecture.md
    ├── deepseek.md
    └── student_parts.md
```

## Что находится в main.py

Сейчас игровая логика находится в файле `main.py`.

Этот файл лучше считать готовым ядром проекта. Его можно показывать детям, но менять его на первых занятиях нужно осторожно.

Внутри `main.py` есть несколько крупных частей:

- функции вывода информации;
- функции выбора действий;
- функции допросов;
- функция финального обвинения;
- главный игровой цикл.

## Что находится в data.py

Файл `data.py` хранит контент игры.

В нем находятся:

- настройки сложности;
- описание дела;
- правильный преступник;
- правильное объяснение;
- список подозреваемых;
- вопросы для допроса;
- ответы подозреваемых;
- список улик;
- список подсказок.

Именно `data.py` удобнее всего давать студентам для первых самостоятельных изменений.

## Что находится в deepseek_client.py

Файл `deepseek_client.py` нужен для будущего подключения DeepSeek.

Сейчас он работает как учебная заглушка:

- собирает промпт для подозреваемого;
- возвращает готовый ответ из `data.py`;
- показывает короткий комментарий к финальной версии игрока.

Позже в этом файле можно заменить заглушку на настоящий запрос к API.

## Данные игры

Данные игры сейчас хранятся в `data.py` прямо в Python-словарях и списках.

Главные структуры данных:

- `DIFFICULTY_SETTINGS` - настройки сложности;
- `CASE_DATA` - описание дела и правильный ответ;
- `SUSPECTS` - подозреваемые;
- `CLUES` - улики;
- `HINTS` - подсказки.
- `INTERVIEW_QUESTIONS` - вопросы для допроса.

Такой вариант удобен для первых занятий, потому что детям не нужно сразу изучать JSON, базы данных или API.

Позже данные можно вынести в JSON:

```text
case_data.json
```

## Ядро игры

Ядро игры - это логика, которая управляет расследованием.

В текущей версии ядро состоит из функций:

- `create_game_state()` - создает состояние новой игры;
- `play_game()` - запускает расследование;
- `show_game_menu()` - показывает меню расследования;
- `interview_suspect()` - проводит допрос;
- `show_hint()` - выдает подсказку;
- `make_accusation()` - проверяет финальный ответ.

## Состояние игры

Состояние игры хранится в словаре `game_state`.

В нем есть:

- выбранная сложность;
- количество оставшихся вопросов;
- количество оставшихся подсказок;
- список изученных улик;
- история допросов.

Пример:

```python
{
    "difficulty": "Средний",
    "questions_left": 6,
    "hints_left": 2,
    "viewed_clues": [],
    "question_history": []
}
```

## Игровой цикл

Игровой цикл находится в функции `play_game()`.

Он работает так:

1. игрок выбирает сложность;
2. создается новое состояние игры;
3. показывается описание дела;
4. открывается меню расследования;
5. игрок выбирает действия;
6. цикл повторяется, пока игрок не назовет преступника или не выйдет в главное меню.

## Допросы

Допросы работают через готовые ответы подозреваемых.

У каждого подозреваемого есть словарь `answers`.

Пример:

```python
"answers": {
    "1": "Я был в переговорной.",
    "2": "Я ничего странного не заметил.",
    "3": "Аня выглядела испуганной."
}
```

В первой версии это надежнее, чем сразу подключать DeepSeek, потому что игра не зависит от интернета и API-ключей.

## Подсказки

Подсказки хранятся в списке `HINTS`.

Количество подсказок зависит от сложности.

Функция `show_hint()`:

- проверяет, остались ли подсказки;
- показывает следующую подсказку;
- уменьшает счетчик подсказок.

## Финал расследования

Финал находится в функции `make_accusation()`.

Игрок выбирает подозреваемого и пишет свою версию.

Программа:

- сравнивает имя выбранного подозреваемого с `CASE_DATA["criminal"]`;
- сообщает, верный ли ответ;
- показывает версию игрока;
- показывает правильное объяснение.

## Где подключать DeepSeek

DeepSeek лучше подключать не сразу в игровое ядро, а через отдельную функцию.

Например, позже можно добавить функцию:

```python
def ask_deepseek(prompt):
    pass
```

После этого ее можно использовать:

- в допросах;
- в генерации атмосферных описаний;
- в анализе финальной версии игрока.

Подробная инструкция находится в файле `docs/deepseek.md`.

## Что лучше оставить готовым

Для детей 10-12 лет лучше дать готовыми:

- запуск программы;
- главный игровой цикл;
- хранение состояния игры;
- проверку неправильного ввода;
- финальную проверку преступника;
- безопасную заглушку DeepSeek.

## Что можно дать студентам

Студентам можно дать:

- изменить меню;
- придумать новое дело;
- добавить подозреваемых;
- добавить улики;
- написать новые вопросы и ответы;
- придумать подсказки;
- улучшить тексты;
- протестировать игру.

Подробное разделение находится в файле `docs/student_parts.md`.
