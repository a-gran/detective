# Будущее разделение задач

Этот документ помогает решить, какие части проекта дать студентам, а какие оставить готовыми.

Сейчас проект уже можно запустить и пройти от начала до конца. Это базовая версия, которую можно использовать как основу.

## Главные файлы для обучения

В проекте есть два главных Python-файла:

- `main.py` - готовое ядро игры;
- `data.py` - данные игры, которые удобно менять студентам.

На первых занятиях лучше чаще работать с `data.py`, потому что там можно менять сюжет, персонажей, улики и подсказки без переписывания игровой логики.

## Главный принцип

Для детей 10-12 лет лучше разделять задачи так, чтобы никто не был единственным владельцем критически важной части.

У команды есть общий пул задач. Несколько участников могут делать одну и ту же задачу разными способами. Потом команда выбирает лучшую реализацию.

## Что лучше дать готовым

Эти части лучше дать студентам уже готовыми:

- запуск программы;
- главный цикл меню;
- создание состояния игры;
- проверка неправильного ввода;
- сравнение финального ответа;
- базовая структура данных;
- запасной режим без DeepSeek;
- документация по архитектуре.

Причина: если эти части сломаются, вся игра перестанет запускаться.

## Что можно дать студентам

Эти части подходят для самостоятельной работы:

- новые тексты меню;
- новое описание дела;
- новые подозреваемые;
- новые улики;
- новые вопросы для допроса;
- новые ответы персонажей;
- новые подсказки;
- улучшение финального объяснения;
- тестирование прохождения игры.

## Команда 1: игровой процесс

Команда 1 может работать над тем, как игрок проходит игру.

Пул задач для команды:

1. Улучшить главное меню.
2. Улучшить меню расследования.
3. Добавить новые уровни сложности.
4. Улучшить историю допросов.

Возможные улучшения:

- добавить пункт "Краткая сводка";
- показать, какие улики уже изучены;
- добавить подтверждение перед финальным обвинением;
- сделать более понятные сообщения об ошибках;
- добавить счетчик выполненных действий.

## Команда 2: контент и история

Команда 2 может работать над делом, персонажами и уликами.

Пул задач для команды:

1. Придумать новое дело.
2. Добавить новых подозреваемых.
3. Добавить новые улики.
4. Написать новые диалоги.
5. Придумать новые подсказки.

Возможные улучшения:

- сделать дело более атмосферным;
- добавить ложные следы;
- сделать алиби персонажей интереснее;
- добавить персонажам разные стили речи;
- сделать финальное объяснение понятнее.

## Что можно сделать как конкурс реализаций

Некоторые задачи удобно давать сразу нескольким детям или мини-группам.

Потом команда выбирает лучший вариант.

Подходящие задачи:

- лучший текст описания дела;
- лучший набор подозреваемых;
- лучший список улик;
- лучшее меню;
- лучшие подсказки;
- лучший финальный текст.

Критерии выбора:

- работает без ошибок;
- понятно написано;
- интересно играть;
- не ломает логику дела;
- легко подключить к проекту.

## Что не стоит давать детям сразу

Эти задачи могут быть сложными для начинающих:

- подключение DeepSeek API;
- работа с переменными окружения;
- обработка сетевых ошибок;
- разделение проекта на много файлов;
- сохранение игры в файл;
- графический интерфейс на Tkinter.

Их можно дать позже или сделать вместе с преподавателем.

## Возможный следующий этап

После обсуждения можно разделить проект на еще больше файлов:

```text
main.py
data.py
game_state.py
menus.py
interviews.py
deepseek_client.py
```

Но на первом этапе двух файлов достаточно: `main.py` для ядра и `data.py` для контента.

## Как проводить занятие с готовой основой

1. Преподаватель показывает, как запустить игру.
2. Дети проходят игру один раз как игроки.
3. Преподаватель показывает, где лежат данные.
4. Команды выбирают задачи из пула.
5. Дети делают варианты.
6. Команда сравнивает варианты.
7. Лучшие изменения аккуратно подключаются к общей версии.

## Проверка результата

После каждого изменения нужно запускать:

```bash
python main.py
```

Минимальная проверка:

1. игра запускается;
2. меню работает;
3. можно посмотреть дело;
4. можно посмотреть улики;
5. можно допросить персонажа;
6. можно получить подсказку;
7. можно назвать преступника;
8. игра показывает результат.
