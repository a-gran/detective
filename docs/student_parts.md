# Части проекта для студентов

Этот проект устроен как набор заданий.

Готовое решение ученикам не выдается.

## Что получают ученики

Ученики получают файлы в корне проекта:

- `main.py`;
- `deepseek_client.py`;
- `data.py`;
- `menu.py`;
- `difficulty.py`;
- `game_state.py`;
- `final.py`;
- `case.py`;
- `suspects.py`;
- `clues.py`;
- `interview.py`;
- `hints.py`;
- документацию.

## Что ученики делают

Ученики должны:

- заполнить данные в `data.py`;
- реализовать функции команды 1 в `menu.py`, `difficulty.py`, `game_state.py`, `final.py`;
- реализовать функции команды 2 в `case.py`, `suspects.py`, `clues.py`, `interview.py`, `hints.py`;
- запускать `python main.py` для проверки.

## Что делает data.py

`data.py` не содержит готового дела.

В нем есть пустые переменные и подробные комментарии:

- какой тип данных нужен;
- какие ключи должны быть в словаре;
- какие поля должны быть у подозреваемого;
- какие данные должны совпадать между собой.

Например, имя преступника в `CASE_DATA["criminal"]` должно совпадать с именем одного подозреваемого из `SUSPECTS`.

## Команда 1

Команда 1 отвечает за игровой процесс.

Файлы:

- `menu.py`;
- `difficulty.py`;
- `game_state.py`;
- `final.py`.

Задачи:

- показать главное меню;
- показать правила;
- выбрать сложность;
- создать состояние игры;
- показать меню расследования;
- показать историю допросов;
- сделать финальное обвинение.

## Команда 2

Команда 2 отвечает за расследование.

Файлы:

- `case.py`;
- `suspects.py`;
- `clues.py`;
- `interview.py`;
- `hints.py`.

Задачи:

- показать описание дела;
- показать подозреваемых;
- выбрать подозреваемого;
- показать улики;
- провести допрос;
- показать подсказку.

## Что делает main.py

`main.py` - готовый файл запуска.

Ученики его не пишут.

Он нужен, чтобы проверить, как соединяются все сделанные части.

## Проверка

После каждой маленькой доработки нужно запускать:

```bash
python main.py
```

Если программа пишет `Нужно доделать задание`, значит указанную функцию еще нужно реализовать.

## Независимая проверка

Не нужно ждать, пока другая команда закончит свой файл.

Каждый ученик может проверить свой файл отдельно:

```bash
python menu.py
python difficulty.py
python game_state.py
python final.py
python case.py
python suspects.py
python clues.py
python interview.py
python hints.py
```

Такая проверка запускает только маленький тест внутри выбранного файла.
